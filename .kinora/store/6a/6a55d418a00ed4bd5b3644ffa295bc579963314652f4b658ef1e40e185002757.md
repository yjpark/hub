# Peer hubs: one hop between named hubs

**Chosen.** Each hub has a name — `HUB_NAME`, defaulting to the hostname — and
a static list of peers, `HUB_PEERS=name=addr,…`. It dials every peer and
redials forever, as nodes do. Peers exchange their node registries:

- **Names.** A consumer sees its own hub's nodes by their bare names and a
  peer's nodes qualified by the peer's name: `edger::yolo`. `::` is reserved —
  a node registering a name containing it is refused.
- **Calls.** A call to `edger::yolo` goes one hop, to the hub named `edger`,
  which delivers it to its local `yolo`; a name still qualified after that hop
  (`edger::pc::x`) is refused. Hubs form a full mesh, so there are no loops and
  no multi-hop routes. A hub's own name is just a longer way to say a local
  node.
- **Events.** While anyone on a hub subscribes to events, the hub holds one
  subscription per peer to that peer's own events (never ones the peer carries
  from elsewhere), and fans them out locally by prefix, like its own; with no
  subscriber, nothing crosses. A subscriber that falls behind on carried events
  is dropped, as for local ones. Remote events arrive with their topics
  unchanged; one published during a peer's redial is missed.
- **Liveness.** A peer that drops — or stops answering keepalive pings — takes
  its nodes out of the view until it redials; nothing is persisted. A peer's
  nodes appear in `topology()`; topology *subscriptions* do not carry them.
- **Config errors.** A peer named twice, or named as the hub itself, is
  refused.

**Why.** One hub per incus host (pc, edger), each host's nodes dialling their
own hub, and only hubs crossing hosts: a host works alone when the other is
off, and a node needs no route to any other host (edger's yolo cannot reach
pc's ZeroTier address).

**Rejected.** Nodes dialling every hub (every node needs a route to every
host). One hub for all hosts (nothing works on a host while the hub's host is
off). Discovery (ZeroTier multicast is unreliable; two hosts need no
discovery). Forwarding every event to every peer (traffic when nobody
watches). One upstream subscription per local subscriber and prefix (it
exhausts the peer connection's concurrent calls past 64 subscribers). Qualifying with `@` (kept free for other uses).

**Open.** The hub-to-hub link is protected only by the private network
(ZeroTier, the incus bridge), as nodes are today; peer authentication comes
later.

**Escape hatch.** No `HUB_PEERS`: a hub alone, exactly as before.
