# Finding — subscribe_topology returns at once, so its channel never carries an event

**Observed** (21 Oct, building the event channel). A vox channel streams
*within its call* (vox's own `channel()` docs). `subscribe_topology` adds the
`Tx` to the fan-out and returns immediately, so the channel closes with the
call: every later broadcast to it fails and the subscriber is dropped. No test
exercises topology delivery end to end, which is how this went unseen.

**Fix shape** (as `subscribe_events` now does): hold the call open until the
subscriber is gone, and send a first event that says the subscription is
live, so a subscriber cannot miss a change between subscribing and listening.
