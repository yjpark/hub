# Spec — the hub carries events it never reads

**Contract.** A consumer may **publish** an event — a **topic** (a string)
and a **payload** (bytes the hub never reads) — and may **subscribe** to every
event whose topic starts with a prefix, receiving them as a stream. The hub
delivers each published event to every subscriber whose prefix matches, in
the order it received them, and tells the publisher how many subscribers it
reached. Delivery is live only: an event published while nobody listens is
gone, and a hub restart loses subscriptions, never anything a subscriber was
promised to find later. A subscriber whose stream has gone away is dropped
silently, as a topology subscriber is.

**A publisher never waits on a subscriber.** Each subscriber has a bounded
queue; one that falls too far behind is dropped, and re-reads what it follows.
A subscription's first event (`hub/subscribed`) says it is live, so nothing
published after it is missed. Prefixes are plain string prefixes — callers end
them with `/`; an empty prefix is everything. `hub/` topics are the hub's own
and refused to publishers; a payload has a ceiling (64 KiB): publish a pointer,
not the thing.

**Chosen.** Live fan-out of opaque events, beside the topology tail. kudo's
console needs to see the loop move — an item enqueued, a claim taken, a
submission landing — without polling a store, and the writers of those
events (workers, the console) already hold a hub connection. Topics are
strings with prefix matching so a console can follow one context
(`kudo/context/<id>/…`) or everything (`kudo/`) without the hub knowing what a
context is.

**Rejected.** The hub interpreting events (it routes, it never owns — every
payload stays the publisher's). Persisting events in the hub (the store is
the record; an event is a nudge to read it). Events from nodes only (the
loop's writers are consumers — a worker's shim, the console).

**Escape hatch.** A subscriber that missed events (it connected late, the
hub restarted) re-reads the store it was being told about; events are never
the only copy of anything.
